## v1.1.5（2026-10-14）

第五十一批（AI 零提供商态 + RSSHub 失败归类）与第五十二批（添加订阅六条）。

### AI 设置
- **零提供商态**：尚未配置任何提供商时不再渲染空卡片，标题行显示「当前使用：无（尚未配置提供商）」
- **内联新建**：点「+ 添加」直接展开新建表单，保存成功才落库（取消即消失，不产生半成品数据）
- **折叠交互**：点已选中卡的头部可折叠表单，再点重新展开
- **不可用卡不算当前使用**：缺 model 的提供商卡不再被当作「当前使用」（后端将 activeId 归空）；依赖模型的控件联动禁用
- **可删到 0 张**：删除按钮常显，删到 0 张合法且立即落库
- 订阅/文件夹右键「新建规则」时，若已有规则则复用 position 最靠前的那条并提示「已并入」，不再新建重复规则

### 刷新错误提示
- RSSHub 抓取失败按原因归类（路由不存在 / 上游失败 / 不可达），前端翻译成人话展示，不再抛裸错误

### 添加订阅
- **默认命名兜底**：抓取失败或 feed 无可读标题时，不再拿整条 URL 当名称，改用「主站域名 + 路由尾段」生成默认名
- 编辑订阅名称清空后可直接保存 = 触发重抓取恢复默认名（原来报 400）；名称行增加 URL 复制按钮
- 「更多选项」面板改为在按钮下方展开
- **条目跳转**：点条目的源名/图标跳转并选中该订阅；列表头出现返回按钮，可还原跳转前的选中状态
- **同域名自动归组**：添加同域名散订阅时提示自动归入该域名分组（可取消）；普通 feed 按订阅地址 host 判断，RSSHub 聚合器不参与
- 自动化规则「无名称」也可预览（保存时仍要求填名称）

### 升级命令

```bash
docker pull ghcr.io/kue02/krss:latest
# 或指定版本
docker pull ghcr.io/kue02/krss:1.1.5
```

本版无数据库迁移，库结构无变化。
