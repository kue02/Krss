# v1.1.1

2026-10-09 发布。自 [v1.1.0](https://github.com/kue02/Krss/releases/tag/v1.1.0)（2026-09-26）以来的 9 个提交。

## ✨ 新功能

- **通知视图：时间线里直接展开成完整阅读器**。展开容器不再是一个阉割版正文，而是挂上完整的正文页——工具栏（加入星标 / 标为未读 / AI 摘要 / 翻译 / 查看原文网站 / 阅读模式 / 打开原文）、大纲、AI 摘要、翻译全部可用。展开时自动隐藏卡片标题，点页面空白处一次收起全部展开项。
- **社交视图：图片区按原图比例显示**。取代原先固定 112×112 的正方形缩略图——单图按真实比例铺满并按视口封顶、两侧留边；同比例多图横排；混合比例走网格且**零裁切**；多图不再只取前 3 张。
- **视频悬停预览：支持点击跳转与拖拽快进**。进度条换成 HeroUI Slider，左右显示当前 / 总时长，另有播放暂停与「新窗口打开」两颗按钮。
- **引文内图片与普通条目走同一套自适应逻辑**。引文图不再被压成小方块，改为铺满引文宽并保持原图比例；同一引文内多图按张数分行。

## 🐛 Bug 修复

- **RSSHub 订阅图标不再全部塌成实例 logo**。经由 RSSHub 订阅的 25 个源会共用同一个实例 favicon，看上去就像「这批源没图标」。现在会按订阅路由反解真实站点（telegram / twitter / youtube / weibo / bilibili / zhihu / github / xiaohongshu / douyin / jike），优先使用频道头像；识别不出上游站点时宁可不抓，也不用实例 logo 冒充。**存量条目在服务启动时自动回填，不需要手工清缓存。**
- 社交条目的图片重复显示修掉两处：引文里的图不再同时出现在图片区；缩略图与引文图是同一张时不再重复渲染。
- 视频悬停预览此前完全无法工作（正文懒加载完成后播放中的 `<video>` 会被卸载重挂），点击进度条还会被误判成「鼠标离开」而重置播放。

## 🎨 改进

- 社交视图正文页去掉标题（社交条目基本都没有标题），作者头像改用订阅源图标，不再是通用人像图标。
- 正文图片的尺寸判断改为三级兜底：HTML `width/height` 属性 → 本地缓存 → 加载完成后实测回写，加载完按真实比例重排。
- 视频控制条的按钮从非法嵌套的 `<button>` 改为 `div[role="button"]` + Enter/Space，键盘与读屏语义修正。
- 通知视图展开容器不再与外层套两层滚动条，展开后的吸顶态改为从容器自身量取。

## 🔧 内部

- 后端图标解析与自动回填新增 241 行测试；前端图片解析、自适应盒子、视频控制条补齐测试。前端共 **112 个测试文件 / 1025 个用例**，后端全仓测试通过、`golangci-lint` 0 问题、类型检查 0 错。
- **发布流程改进**：新增 `docs/releases/` 目录存放人工撰写的版本说明，GitHub Release 直接采用这份按「新功能 / Bug 修复 / 改进 / 内部」分类的更新说明，不再只贴提交历史。以后发版请在打 tag 前先写这个文件。

## 升级

```bash
docker compose pull && docker compose up -d
```

**注意**：这次包含订阅图标的自动回填，升级后服务启动时会重新抓取一批图标，属正常现象。
