## [1.3.0] - 2026-11-24

### Added

- **文章视图新增「Inoreader列表」布局**：来源图标 + 加粗标题 + 右侧「来源 · 时间」的紧凑列表，点开条目在列表内直接展开正文、还能继续下滑看后续条目，与列表共用一套滚动，同时只展开一条、点别的自动切换。（想法来自 `@YuanLai` https://meta.appinn.net/t/topic/96655/3?u=kue）
- **Inoreader 列表的细化设置**：行高（紧凑 / 宽松）、行内快捷按钮三档（悬浮滑出 / 悬浮显示 / 常显）、正文栏样式（原样 / 卡片）、移动端「完整标题优先」；打开后目录与阅读进度各有一套并锚定屏幕。
- **列表行右键菜单**：Inoreader 列表与缩略图列表的行都支持右键菜单（标为已读、加星标、标记上方为已读、豁免这类内容、按此条新建规则、订阅组等），星标项紧随已读项。
- **列表行左侧快捷按钮**：每行最左新增「已读 / 未读 + 星标」快捷按钮（桌面悬浮、手机左滑圆形按钮），不必长按也能操作。
- **「向下」合列阅读**：正文接在被点的那一行后面、与列表共用一套滚动，桌面与移动端一致。
- **正文布局扩展**：正文面板新增「从下往上」推入方向，以及「正文覆盖条目栏」的文章布局模式。
- **双栏分界限可自动隐藏**：新增「平时也画 / 自动隐藏」设置（双栏 = 侧栏 + 内容），自动隐藏时平时不画线、悬浮才显示；首次打开 Inoreader 列表时，若图片 / 社交媒体 / 通知视图已关闭分界线，会询问文章视图是否也关闭，之后随时可在设置里切换。
- **智能文件夹**：原「筛选视图」升级为可展开的智能文件夹，能展开看到命中的订阅与未读数；侧栏文件夹未读数按层级递归汇总，计数口径与订阅一致。
- **自动化编辑器重设计**：新建规则 / 新建视图改为卡片化分区，规则与视图的范围支持多选文件夹，范围选择器重绘。
- **AI 免费翻译通道扩容**：新增微软、B 站两条免费通道，共 4 条（Google / 有道 / 微软 / B 站），可按顺序轮换、一条失败自动切下一条，并带通道健康度与限速冷却；新增「AI 请求走代理」开关。
- **备份升级**：设置与全量备份合并为按分区多选导出，可选择是否包含敏感凭证（补全排除名单并持久化 MCP OAuth 令牌）；新增整库 JSON 完整备份的导出与导入；OPML 导入导出同时携带订阅与文件夹的内容类型。
- **侧边栏文件夹增强**：文件夹支持多层级移动与桌面拖拽排序，排序方式持久保存；文件夹行点三角 / 文字展开下拉，点行内空白切换选中。
- **高级页新增「实验性设置」分区**：集中放置图片悬停大图、图片墙、悬停正文、缩略图列表、文章列表等实验布局，默认全部关闭。
- **字号与行高改为数字步进器**，可精确增减。
- **图片查看支持缩放与平移**，移动端视频接近全屏。
- **文章缓存清理可配置保留期**：可设置已读文章缓存保留天数，以及清理记录（墓碑）的保留天数。

### Changed

- **设置窗口改为非模态浮窗**：去掉背景遮罩，可拖到窗口外，背后页面可直接操作、点背景不关闭，只认右上角关闭与 Esc；每次打开回到屏幕正中。
- **移动端左侧抽屉重设计**：加宽、圆角，行高与分区层次重排，订阅 / 文件夹行统一为触控高度。
- **侧栏文件夹行去掉文件夹图标**，改用展开三角 + 文字，层级更清爽。
- **文章列表顶栏与移动底栏随滚动收起 / 恢复**：Web 顶栏只在 Inoreader 合列阅读且向下滚时收起，正文标题栏优先；移动端底栏随滚动隐藏；下拉刷新改为顶部细进度条。
- 文章「列表图片」「摘要行数」仅在传统三栏显示，行高设置移入文章设置；Inoreader 列表沿用全局「未读标记」样式。
- 图片视图默认布局改为网格。
- AI 请求走代理默认关闭（默认直连）。
- 新装用户的免费翻译通道默认全部开启；已有用户保留原来的单通道配置，不自动扩容。
- 文章缓存保留天数改为改动即自动保存（移除保存按钮）。

### Removed

- 移除列表底部「星标 / 未读 / 全部」的筛选胶囊。

### Fixed

- 修复向下合列点开条目后，视口被甩到正文底部的问题（Web 与移动端）。
- 修复合列阅读时正文工具栏浮在正文中部（选中正文时改关虚拟化、恢复吸顶）、卡片样式目录被裁剪、点击条目顶栏闪烁，以及未选条目时多出悬空分隔线。
- 修复阅读时顶栏收起 / 展开的抖动与回顶不复位、手机点开条目闪藏顶栏；正文标题吸顶与正文顶栏优先级按预期生效，移动端正文标题常显并避让顶栏。
- 修复清理文章缓存后已读文章回流为未读（记录指纹并保留 180 天，刷新不再回流），清理不再重置 ETag，且只清理已读、未收藏，保留星标与未读。
- 修复星标乐观更新时条目从列表消失；取消星标只在星标视图即时摘除，星标徽标在文章 / 社交媒体两视图统一。
- 修复触屏双击缩放误关、视频全屏按钮不可点、图片查看器可访问性问题。
- 让免费翻译通道更稳：网络失败与有道限流计入冷却、单次请求设总预算、真实超时按网络失败处理、主动取消不计入健康度。
- 修复新建文件夹与订阅返回的排序号不准、新建项排序号未追加末尾，以及把文件夹移动到不同类型的文件夹时缺少校验。
- 修复侧栏文件夹拖拽重影、拖拽后保存失败与根区拖放落点不准。
- 修复智能文件夹计数显示为命中总数而非未读数、命中订阅未按当前条目重算、改名后角标不更新。
- 修复自动化多选范围在启用 / 停用、排序、视图刷新链路被丢弃。
- 修复设置非模态浮窗的拖拽越界、Tab 在窗内边界才出窗等问题；缓存设置补空输入保护与卸载补发。
- 修复文章视图分界限已关闭时仍弹「要不要也关」、点回同档被当作已改动。
- 修复 AI 连通性测试与模型探测未走代理（现受「AI 请求走代理」控制）。
