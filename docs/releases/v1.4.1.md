## [1.4.1] - 2026-11-26

### Added

- **正文里的视频能直接播了**：B 站、YouTube、Wistia 的播放器内嵌在正文中，不用跳出去看；其余站点默认点一下再加载，也可在设置里加白名单。
- **正文视频播放器换新**：带完整控制条（播放、进度、音量、倍速、全屏），16:9 黑底圆角，下方保留来源站点入口。
- **订阅源可以改地址**：编辑订阅时点「修改」即可换地址，地址过长可横向滚动查看；改成已存在的地址会提示合并，不会建出重复订阅。

### Changed

- **视频相关设置挪到「通用」**，并新增「额外站点白名单」：内置 B 站 / YouTube / Wistia 无需填写，其它站点自己加域名或完整链接。
- **阅读时长按你实际看到的正文估算**：开启阅读模式或译文后，时长不再按原始 RSS 正文算。

### Removed

- **不再有大屏视频预览浮层**：点正文视频直接在正文内播放，不再弹出独立窗口。

### Fixed

- **iOS 右滑返回不再闪一下空的正文栏**，也不会再出现「像退了一个网页」的重复历史。
- **iOS 右滑返回时左侧抽屉不再闪现**，手势也只在列表页生效，不会在正文里误触。
- **iOS 右滑返回的手势预览不再是一片空白**，滑回列表时看到的是真实列表内容。
- **手机上关闭图片预览不再跳回列表顶部。**
- **手机正文页底部的翻页胶囊与返回顶部按钮抬高**，不再压在 home indicator 上。
- **打开手机侧栏时键盘焦点直接进面板**，不用再按一次 Tab。
- **阅读模式下的阅读时长不再偏小**，与正文实际长度一致。
