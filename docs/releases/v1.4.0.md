## [1.4.0] - 2026-11-25

### Added

- **通知视图新增「卡片流」布局**：和时间轴一键切换（默认仍是时间轴）。按日期分组，一条一张卡片，看起来更清爽。
- **正文栏外框可选样式**：卡片式正文栏可以在「淡边框（默认）/ 无边框 / 全宽」之间切换。
- **重开应用更快**：列表、已读状态和正文都缓存在本地，重开或刷新后首屏更快出来。
- **刷新更省心**：每个订阅按自己的更新频率自动调整刷新间隔、错开时间，不会一窝蜂同时刷；切回前台立刻刷新。
- **手机端左滑按钮样式可选**：可以保留旧版动作按钮的样子；Inoreader 列表也恢复了长按菜单。
- **点图片外的空白处就能关掉图片预览。**

### Changed

- **大幅改善卡顿、掉帧的问题**：列表滚动、切换视图、打开正文和图片预览都更顺滑。
- **正文和社交页的标题更精致**：改成杂志式的标题＋作者 / 来源 · 日期 · 阅读时长，标题字号收小，正文排版更耐读。
- **卡片档正文栏顶部工具栏恢复磨砂背景**，滚动后圆角也不会再缺一块。
- **第一栏分界线改为自动跟随布局**：三栏时一直显示；双栏时平时不显示、鼠标移上去或用的时候才出现；第二栏那条始终悬浮显示。

### Removed

- **外观设置里不再有「双栏自动隐藏分界限」和各视图「显示分界限」的手动开关**，改由上面说的自动跟随布局决定。

### Fixed

- **图片预览更顺手**：缩放跟手了，捏合和平移不再打架，点空白处或双击都能正常关闭，视频全屏按钮也能点了。
- **下拉刷新不再误触**：横滑条目不回弹到刷新，刷新也更稳定。
- **手机侧栏抽屉更流畅**：滑出不掉帧，手势收得干净。
- **手机端左滑更跟手**：不再卡顿或松手判定错。
- **长列表用键盘操作不再断链**：滚动到新加载的行也能标已读、键盘选中不丢焦；通知时间线用 j/k 跨日期也能正常跳。
- **正文打不开时不再空白**：详情请求失败会先用列表里已缓存的内容给你看，不再只显示「选择一篇文章」。
- **多账号切换不再串数据**：本地缓存按账号分开，切换、登出、超时都更稳。
- **启动更快**：清理缓存改到后台做，慢设备也不会卡在首屏。
- **偶尔失败的订阅不会长时间不再刷新**，之后会正常重试。
- **键盘焦点框不再被裁掉。**
- **通知卡片流看得更清**：已读卡片对比度、日期遮挡标题、单列 / 双列切换都修好了。
- **翻译和摘要更稳**：失败会自动重试，点开条目不再卡顿。
- **手机正文末尾留白加大**，滚到底不再贴边。
- **内嵌阅读器打开图片更清晰。**
