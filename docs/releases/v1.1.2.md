# v1.1.2

2026-10-10 发布。自 [v1.1.1](https://github.com/kue02/Krss/releases/tag/v1.1.1)（2026-10-09）以来的 22 个提交。

## ✨ 新功能

- **正文进视线就后台预载**。订阅上设了「正文打开方式（阅读模式）」「自动摘要」「自动翻译」的源，条目**滚进视线就自动在后台把正文抓好、摘要跑好、翻译跑好**；点进去直接就是结果，不再等那一下。默认开启，可在「设置 → 阅读」关闭，并能调并发数（1 / 2 / 3 / 5）。只对配过这三项的源生效，没配的源一个请求都不会发。
- **订阅级「自动翻译」现在也翻正文**。此前订阅上打开「自动翻译」只翻列表里的标题和摘要，正文要手动点；现在打开正文也会自动翻，口径与「自动摘要」一致（条目级标记 > 订阅级 > 全局）。
- **第二栏条目右键，一并给出所属订阅的整组操作**。右击条目时，菜单里除了条目自己的操作，还有这条所属订阅的全部操作（刷新 / 编辑 / 移到文件夹 / 更改类型 / 复制订阅地址 / 打开主站 / 新建过滤规则 / 删除），与第一栏订阅右键**逐项一致**（同一份实现）。通知视图的时间线卡片同样生效。

## 🐛 Bug 修复

- **同一篇正文不再被翻译两遍**。预载正在后台翻的时候点进去，正文页会订阅它已经跑出来的分块、边出边显示，不再另起一次模型请求（此前两条路径各跑一遍，本地小模型下等于「打开后又等一遍」）。
- 正文里的裸 URL（`https://…` 纯文本）现在会自动变成可点链接。
- 社交视图点卡片里的图片只开灯箱，不再连带跳进正文。
- 预载的视口观察器此前对「挂载后才渲染出来的行」完全不生效（极端情况下一条都不会预载），已修。

## 🎨 改进

- **「滚动标已读」不再强制**：原来「通用」那一档会硬压所有视图，现在「通用」只是默认值，「设置 → 外观」把按视图的档位合并成一行四档（跟随通用 / 点开才标已读 / 滚出顶部 / 看到即已读）。
- README 重写：定位、功能清单、界面截图全部更新。

## 🔧 内部

- 新增正文渲染基准装置（解析侧 A/B、端到端交错 A/B、重渲染），可在本地以生产构建复跑；顺手去掉两处无谓开销（图片清单在每次父渲染时重扫全篇、解析管线的 schema 与 processor 每次调用重建）。
  **诚实结论**：实测点击到首屏的耗时**主要不在解析**（解析 ~12ms），而在点击后约 1s 的同步 React 渲染 + DOM 构建，本版未做结构性重构。
- 修复一处**体积回归**：语言检测（ELD 的 n-gram 表约 1.5 MB）此前被静态引入了首屏包，主
  chunk 从 0.76 MiB 涨到 2.31 MiB、顶穿 PWA 预缓存上限导致构建失败；现已改回按需加载，
  首屏包回到 0.77 MiB，ELD 单独成块。
- 前端测试 **123 个测试文件 / 1119 个用例**全部通过；后端全仓测试与 `golangci-lint` 0 问题。

## 升级

```bash
docker compose pull && docker compose up -d
```

**⚠️ 端口变更**：本版默认监听端口从 `8080` 改成 `8090`。

- 用仓库自带 `docker-compose.yml` 的：已经改成 `8090:8090`，直接升级即可。
- 自己写过映射的（例如 `8080:8080`）：请改成 `8090:8090`；想继续用 8080 也可以，给容器加一条环境变量 `KRSS_ADDR=:8080` 即可。

本版没有数据库结构变更，升级不需要手工迁移；旧镜像标签建议留着做回滚保险。
