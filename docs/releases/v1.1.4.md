## v1.1.4（2026-10-13）

第五十批：AI 设置收口 + 网络代理优化。

### AI 设置
- **分场景模型**：翻译 / 摘要 / 自动化（AI 条件、用文字创建规则）可各自选用已保存的任一提供商配置，默认跟随「当前使用」；被删提供商自动退回跟随
- **提供商卡片化**：已保存的提供商改成紧凑卡列表（名称 + 类型 + 模型 + 当前徽章），点卡片展开编辑，保存 / 测试跟在卡底
- **行为区自动保存**：摘要语言 / 翻译通道 / 自动翻译 / 自动摘要 / 速率限制等改动后自动保存（防抖 800ms，行内反馈）；请求参数 JSON 非法时不保存；提供商表单仍手动整体提交
- 翻译场景可选免费通道且不再要求配主模型

### 网络
- **智能代理模式**（可选，全局与订阅/文件夹级都支持）：先直连（4 秒短探测），不通自动换代理，并**按目标域记住结论**——直连成功下次直接直连、代理成功下次直接走代理，不再每次白等超时
- 智能记忆可在网络页查看与一键清空（`GET/DELETE /api/proxy/memory`）
- 关闭代理后配置收成一行摘要（点开仍可编辑），测试连接按钮在代理关闭时也可用
- 订阅 / 文件夹代理覆盖从三态扩为四态：跟随 / 直连 / 走代理 / 智能

### 其他
- 数据库迁移 29（proxy_domain_memory 表，升级零变化）

**CI**：Frontend/Backend Test 全绿；Lint 红为既有基线（前端 eslint 旧账 2026-09-24 起；后端 golangci-lint 与 Homebrew go 1.27.2 stdlib 兼容问题，本地干净 HEAD 同报）。
