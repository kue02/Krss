## [1.4.2] - 2026-11-26

### Added

- **检查 Krss 自身有没有新版本**：设置 →「关于」新增「版本更新」区，显示当前版本、最新版本、发布页面和上次检查时间，打开即自动检查一次，也能手动「重新检查」；有新版本时页面顶部出现显眼提示，点开可看更新内容和下载入口。
- **登录后在任意页面都能收到更新提示**：有新版本时右下角常驻一条提示，点「查看更新内容」直接打开更新详情，不用先进设置页。
- **更新详情列出「自当前版本之后的全部版本」**：每条版本可单独展开，默认展开最新一版，附发布说明与下载链接。
- **正文视频恢复悬停静音播放**：鼠标停在正文视频上就地静音预览，移开回到封面；点播放键后可正常有声观看，移开不再暂停。
- **列表头新增「可视区域以上标为已读」**：一键把列表顶部到当前屏幕最后一条标为已读（图标为「上箭头 + 顶横线」），右键仍能「全部已读」（保留原双勾图标）；移动端主按钮改为标记可视区，「全部已读」收进「更多」。
- **移动端左侧栏弹出动画**：打开左侧栏更顺滑，滑入带轻微缩放，不掉帧、不回弹。

### Changed

- **视频按需预载，更省流量**：鼠标停留才高预载、进入视野只取元信息、滚出视野不再预载，浏览列表时不会为每个视频偷偷下载。
- **已读、加星后条目不再当场消失**：只变灰留在原位，切换视图或筛选时才按规则移除；普通视图里「全部已读」也会即时清掉未读圆点。
- **暗色模式更清楚**：暗色下提亮强调色与次要文字，修掉按钮、图标黑底黑字看不清的问题；外观设置里「主题色」色块显示暗色下实际生效的颜色。
- **「暂无文章」空态统一居中**：文章、图片等视图的空态统一为「图标 + 暂无文章」并居中，手机上不再贴顶。

### Fixed

- **视频加载和拖动进度更快**：后端按浏览器的分段请求向上游取流、边下边播，并把整段视频缓存到本地，再次播放几乎即开；几十 MB 的长视频也能缓存，不再整段读进内存。
- **移动端滚动到顶部时底栏偶尔还是隐藏**：现在到顶会正常显示。
- **移动端订阅栏长按弹出的菜单无法上下滑动**：修好后菜单内可正常滚动，遮罩外仍锁住背景列表。
- **条目右滑松手后整条灰底不回弹、动作面板圆角对不齐**：现在松手即恢复，动作面板贴合卡片圆角。
- **社交视图里点视频会跳到正文**：现在在条目里就地播放。
