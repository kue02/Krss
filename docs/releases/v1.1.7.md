# v1.1.7

2026-11-21 发布。自 [v1.1.6.2](https://github.com/kue02/Krss/releases/tag/v1.1.6.2)（2026-11-01）以来的 111 个提交。

## ✨ 新功能

- **插件系统上线**。设置里的「插件」页集中管理内置插件与外部插件；内置 Bark 推送、RSSHub 适配、GitHub 头像。外部插件可以用 zip 包安装，安装后默认停用，启用后才加载；卸载时会二次确认，插件目录归档、插件设置与数据一并清理。
- **插件可以扩展界面**。插件可以向条目右键菜单、列表工具栏、阅读器工具栏、阅读器正文条、订阅右键菜单、过滤规则编辑器、插件设置页、命令面板、视图工具栏等位置加入操作，也可以注册独立视图或自定义页面；自定义页面运行在沙箱 iframe 中，只能通过受控 bridge 读写插件数据。
- **GitHub 订阅显示账号头像**。新增 GitHub 头像插件：GitHub 用户时间线以及 Releases、Commits、Tags 等仓库订阅会抓取账号头像；已有 GitHub 源在刷新后自动把默认 favicon 换为头像，通过 OPML 导入的源同样生效。
- **设置新增「关于」页，外观页重做**。关于页显示当前版本、开源许可证与技术栈；外观页改成分区卡片，主题、阅读与列表、形状、按视图和分类视图的设置集中预览，调整后即时生效。
- **免费翻译通道支持轮换与回退**。免费翻译可以配置多个通道的执行顺序，单个通道限流或失败时自动尝试下一个；全部免费通道失败后再交给已配置的模型兜底。
- **自动化规则可以调用插件动作**。过滤器规则不再只能发 Bark 通知，可以选择插件提供的动作；插件未启用或执行失败时，规则上会显示明确错误。
- **新增 iOS 客户端外壳（MyGo）**。提供复用现有前端的 iOS 薄壳与构建脚本，后端增加跨域支持，可直接连自建服务器使用。

## 🐛 Bug 修复

- **导入的 GitHub 源一直显示默认图标**。以前导入时若头像下载失败会固化站点 favicon，之后刷新也不会重新判断；现在每次刷新都会重新检查图标，成功换成头像，失败也不会退回 favicon 并会下次重试。
- **插件正文装饰跨段落时位置偏移**。跨 `<p>` 等块级元素的装饰会按可见文本重新锚定，不再错位。
- **插件卸载失败后无法重试**。插件目录已归档但清理未完成时，再点卸载会继续完成设置、数据与记录的清理，不再直接报不存在。
- **旧版插件协议不兼容时反复重启**。宿主会识别协议版本不匹配，直接停用并给出提示，不再每 5 秒重启坏插件。
- **卸载后的归档目录被反复扫描**。以 `.removed-` 结尾的归档目录会跳过扫描，不再每轮误报插件 id 与目录名不一致。

## 🎨 改进

- **插件页支持上传安装**。顶部新增「添加插件」，选择 zip 包即可安装；安装提示移到按钮下方。插件卡片会显示内置/外部标识、版本、启用状态与错误信息。
- **Bark 与 RSSHub 设置迁入插件页**。原来的 Bark 全局地址、RSSHub 基地址与密钥会自动迁移到插件设置，旧通知规则继续可用；设置从通用/通知页统一收到「插件」页。
- **Demo 样板插件移除**。设置里不再出现无法使用的 Demo 卡片，相关残留会在升级时自动清理。
- **插件开发文档补齐**。新增 `docs/plugins/`，包含插件清单、Go API、进程协议、沙箱界面与 bridge 文档，方便编写内置或外部插件。

## 🔧 内部

- 插件读路径按插件设置超时，单个插件卡住不会拖住条目详情；外部插件子进程只拿到最小环境变量白名单；插件日志按 5MB 轮转；外部插件协议加入版本校验。
- 新增数据库迁移 31–35：插件状态表、插件数据表、Bark 与 RSSHub 配置迁移、Demo 残留清理；迁移均幂等，保留过滤动作里的未知字段，并兼容旧版 RSSHub 设置备份导入。
- 后端全量测试 23 个包通过；前端 159 个测试文件 / 1326 个用例通过，`tsc -b` 0 错。Docker 镜像同时构建 `amd64` 与 `arm64`。

## 升级

升级前请先备份数据目录里的 `krss.db`、`icons/`、`proxy-cache/` 与 `.env`，再拉取新镜像：

```bash
cd /你的部署目录
docker compose pull
docker compose up -d
```

本版包含数据库迁移 31–35，首次启动会自动执行；迁移是单向的，降级不会回滚数据。旧镜像标签建议保留，回滚时把 `IMAGE_TAG` 改回 `1.1.6.2` 再 `docker compose up -d` 即可。
