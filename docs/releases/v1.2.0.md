## [1.2.0] - 2026-11-23

### Added

- 设置中心整体重设计：订阅、文件夹、通用、插件、自动化、网络、高级、关于，以及「数据控制」「AI」页统一为分区卡片与行式控件，层级更清晰、窄屏更整齐。
- AI 提供商支持一个提供商下挂多个模型：新建或编辑时可自动探测模型、一键全部加入并选择默认模型；翻译、摘要等不同场景可分别指定具体模型。
- 移动端列表条目支持左滑快捷操作：左滑露出「已读/未读切换」和「星标」，点一下即可完成，不必再长按打开菜单。

### Changed

- 自动化规则的条件默认改为「或」组合：任一条件满足即命中。
- AI 提供商切换「当前使用」时会一并保留该提供商已填的 API Key，不再丢失；AI 行为设置未保存时离开会提示，可选择「保存并离开」。
- 设置页控件统一：提供商卡片的协议名本地化，分场景未选择时显示「跟随当前使用」，无描述的卡片标题与图标垂直居中，输入框恢复统一圆角与焦点环，窄屏操作区可换行。

### Fixed

- 在「只看未读」列表里手动标已读（右键菜单、悬停操作、快捷键、移动端操作面板、左滑动作）后，条目不再当场消失：只变灰留在原位，离开列表时才按未读规则移除。
- 兼容忽略 `stream:false`、仍返回流式（SSE）响应的 AI 提供商，连通性测试与翻译不再报错。
- 修复模型翻译偶发整段未翻译的问题（短文本、占位符不再被误判为已译），并修正正文页摘要/翻译的状态显示。
- 摘要缓存恢复时带回原模型来源，顶栏悬浮可显示实际使用的模型。
- 修复星标未读筛选、切换视图后已读残留的问题。
