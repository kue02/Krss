# v1.1.8

2026-11-21 发布。自 [v1.1.7](https://github.com/kue02/Krss/releases/tag/v1.1.7)（2026-11-21）以来的 7 个提交。

## ✨ 新功能

- **移动端界面重做**。手机上的列表、详情、搜索与底部导航按纸页风格重新排版：顶部改为 44px 工具栏，底部增加文章、社交、图片、通知四轨导航；支持全屏搜索、下拉刷新、刘海与底部安全区。桌面端布局保持不变。
- **手机正文支持目录**。阅读长文时从屏幕右缘滑出目录，按标题层级跳转，当前章节会高亮。
- **新增移动端阅读设置**。详情页可以直接调整正文字体、字号、行高与主题，并在面板里实时预览效果。
- **详情页可切换上一条 / 下一条**。阅读页底部显示当前位置与总数，点一下直接翻到相邻文章。
- **条目长按操作**。手机列表长按条目即可标已读、加星标、标记上方全部已读、取消静音、按条目建规则；同一面板里也能刷新、编辑、移动、更改类型、复制地址、打开主站或删除所属订阅。
- **外观新增「移动端样式」**。可以决定手机侧栏是否显示视图切换；长按菜单可选底部面板或贴住手指位置的浮层，默认底部面板。

## 🎨 改进

- **手机列表顶栏重新排布**。刷新当前范围、未读切换、全部标记已读都在顶栏直接可点；搜索收进「更多」，不再单独占一个图标。
- **详情顶栏更安静**。页面在顶部时不显示标题，滚动后才淡入；星标旁增加已读 / 未读切换。
- **移动端底栏改为半透明**，向下滚动时仍能看到内容从底栏下经过；下拉刷新会显示「正在刷新 · 已完成 / 总数」。
- **详情页来源信息增加 24px 圆形头像**，订阅图标缺失时用来源名称首字母代替。

## 🐛 Bug 修复

- **GitHub 订阅头像偶尔不显示**。头像地址改为 GitHub 的头像直链，不再经过会重定向的站点图标地址，订阅刷新后能正常显示账号头像。

## 🔧 内部

- 移动端改动全部限定在手机断点内，桌面端复用原组件与样式。
- 前端 159 个测试文件 / 1326 个用例全过，`tsc -b` 0 错。

## 升级

```bash
cd /你的部署目录
docker compose pull
docker compose up -d
```
