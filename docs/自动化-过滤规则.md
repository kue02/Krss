## 一、它是什么

**规则 = 作用域（全部 / 分类 / 订阅）+ 条件 + 动作**，一套引擎、两个入口：

- **条文式**：订阅右键「为此订阅新建规则」——规则被钉死在某个源上；
- **总体式**：设置 → **自动化** ——同一批规则在设置页统一管理。

这条路是 Inoreader 的三段式（When → If → Then）+ Folo 的动作集 + MrRSS 的执行时机，
三家做法与取舍见 `docs/archive/过滤功能-方案-2026-09-17.md` 的对比表。

## 二、已拍板的语义（不要再讨论，改要重新拍）

| # | 决策 |
|---|---|
| 1 | 一套规则引擎、两个入口（订阅右键 / 设置页），规则自带 scope 三层 |
| 2 | **执行点＝抓取入库之后**，只对**刚入库的新条目**生效，只改自己库里的标记（不碰写入路径、去重与 FTS 触发器） |
| 3 | **冲突语义＝`position` 顺序 + 首个命中即停** + 一条规则内多动作（含正反成对）；例外规则＝「顺序 + 反动作」 |
| 4 | 动作 P1＝`mute` `unmute` `markRead` `markUnread` `star` `unstar` `keepOnly`；**静音＝入库 + `read=1` + `muted=1`**（列表默认隐藏、可回看、可反悔）；`keepOnly` 不命中时退化为静音 |
| 5 | 静音必须**可解释**：条目标签悬停显示「已静音 · 规则名」，规则被删显示「规则已删除」 |
| 6 | 星标视图带 `includeMuted`（用户显式收藏的内容不该被规则藏起来）；「已静音」视图**不叠加"只看未读"**（否则回看视图会被整批藏空） |
| 7 | 迁移号 **21 归本模块**（别的模块要用迁移，从 22 起） |
| 8 | **搜索口径（2026-09-17 用户拍板）：静音条目搜不到** —— `Search` 的 SQL 补 `muted = 0`（与列表默认隐藏一致）**已执行**（回归测试 `TestEntryRepository_Search_ExcludesMuted`） |
| 9 | **动作分界线不变**：P1 = 只改自己库标记的即时动作；**「要出网 / 要花钱」的动作分开对待** —— `translate`/`summarize` 只打「打开时自动」条目标记（入库不花 token），`webhook` 才算真正出网（异步 + 失败可见） |
| 10 | **AI 条件（P3）：默认「只问长文」而不是「每条都问」** —— 正文 <400 字不判定；单次运行最多 5 次、进程内 10 分钟最多 60 次；判定按 `(条目, 主题)` 永久缓存；预览**只吃缓存、绝不新发起调用** |
| 11 | **自然语言建规则（P3）：模型产出不落库** —— 一律先填进编辑器抽屉，由人确认后才保存；被纠正/丢弃的项必须在抽屉里显示（`warnings`） |
| 12 | **例外规则 = 顺序 + 反向动作**：`POST /api/filters/exception` 建的规则排到最前（position 可为负）、只做 `unmute + markUnread`，条件默认「同一链接」；建完立刻放行这一条并记一次命中 |
| 13 | **视图（保存筛选视图）不是规则**：`filters.kind = view` 只筛条目、不写数据、没有动作；引擎完全跳过它；条件求值复用 `MatchConditions` 同一个函数 |

**接口**

```
GET    /api/filters                 列表（含命中数 / 最近命中 / position）
POST   /api/filters                 新建
PATCH  /api/filters/:id             编辑 / 启停 / 调顺序
DELETE /api/filters/:id?revert=true 删除（可选连同撤销它静音的条目）
POST   /api/filters/preview         干跑：扫最近 N 条，回「会命中哪些、会影响多少条」
POST   /api/filters/:id/apply       对历史条目回溯（幂等、首个命中即停，默认扫 500 / 上限 2000）
POST   /api/filters/:id/revert      撤销该规则写入的标记
GET    /api/filters/:id/matches     命中日志（LEFT JOIN 出条目标题与来源名）
POST   /api/entries/:id/unmute      条目级「取消静音」（放一条回来，退回未读）
GET    /api/entries?...&includeMuted=true|&mutedOnly=true
POST   /api/filters/parse           自然语言建规则（LLM → 草稿，**不落库**）
POST   /api/filters/exception       条目级「豁免这类内容」（建例外规则 + 立刻放行）
GET    /api/entries?...&viewId=     按「保存筛选视图」取条目（规则给 viewId → 404）
```

**P2/P3 新增的动作与依赖（2026-09-17 第二轮）**
