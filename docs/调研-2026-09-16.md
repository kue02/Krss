# 调研：Gist × Nextflux（2026-09-16）

调研方式：浅克隆两个仓库读源码（`references/` 各留一份）+ 官方 README 截图视觉精读。**两个项目都没有实际跑起来**，运行时行为未验证。

## 一、事实对照

| 项 | Nextflux | Gist |
|---|---|---|
| 定位 | Miniflux 的第三方 Web 前端（自己不是服务端） | 自托管 RSS 服务端 + 前端一体 |
| 技术栈 | React 19.2 + **JS** + Vite 6 + Tailwind 4.1 | Go 1.25（35.6k 行）+ React 19.2 + **TS** + Vite 8 + Tailwind 4.3 |
| UI 组件 | **HeroUI v3.0.4**（旧 NextUI）+ Radix 少量 | Radix primitives + shadcn 风格 CSS 变量 |
| 状态/路由 | nanostores + dexie，react-router 7 | react-query + zustand + idb-keyval，wouter |
| 前端体量 | src ≈ 12.7k 行 | frontend/src ≈ 27.5k 行（含测试）；components 16.2k |
| 主题 | 亮 3 套（light / stone / leaf）+ 暗 2 套（dark / nord-dark），`data-theme` 驱动 | 仅 light / dark / system |
| 视图 | 侧栏 + 文章列表 + 正文（Reeder 风格） | **article / picture(瀑布流) / notification** 三种内容类型 |
| 正文阅读 | 嵌入渲染 + 图片画廊手势 + AI 摘要 | Readability 沉浸模式 + AI 摘要/翻译 + 代码高亮 |
| 快捷键 | 有，18 项 | **无**（全仓 grep 无相关实现） |
| 字体设置 | 有（字族/字号/行高/标题行数/卡片图尺寸） | **无**（`font-family` 仅出现在 index.css） |
| OPML / 订阅发现 | 有（走 Miniflux API） | 有（后端原生 `/opml/import`、`/feeds/preview`） |
| 后端筛选能力 | — | `feedId` / `folderId` / `contentType` / `unreadOnly` / `starredOnly` / `hasThumbnail` / limit / offset |
| 维护状态 | 523★ / 103 forks / 537 commits，最后提交 **2026-05-20** | 203★ / 15 forks / 298 commits，最后提交 **2026-08-26**（活跃） |
| 许可 | 自定义「随便用」 | **GPL-2.0** |

## 二、界面差异的实质（截图 + 代码比对）

| 维度 | Nextflux | Gist 现状 | 改动性质 |
|---|---|---|---|
| 配色 | 暖灰石质（底 `#e3e1de` / 面板 `#f5f3ef` / 字 `#3f3e3b`），强调色珊瑚红 `#df604d` | 黑/白/纯灰 | 改 CSS 变量（Gist 变量体系已就位） |
| 圆角/阴影 | 卡片 18px、面板 24px、胶囊 28px，多层柔影 + 玻璃 dropdown | 几乎无圆角无阴影 | CSS token 层 |
| 中栏列表 | **卡片式**：160×160 缩略图、来源行、2 行大标题、阅读时间、选中浮起 | 纯文本列表（无缩略图），选中=灰色实心条，栏宽 ~930px | **组件重写**（`EntryListItem` 等）+ 栏宽收窄 |
| 正文区 | 浮层圆角面板（16px 外边距）+ 独立圆形按钮工具条 | 满宽白底 | 布局层 |
| 底部筛选 | Starred / Unread / All 胶囊（珊瑚红选中） | 无控件，但后端参数已支持 | 新组件，接现有 API |

Nextflux 观感来源（代码证据）：`tailwind.config.js` 的 boxShadow/keyframes 扩展 + `src/index.css` 的 `--shadow-custom*` 变量与 5 套 `[data-theme]` token 块 + HeroUI v3 组件类覆写（`.dropdown__popover` / `.button--primary` 等 37 个文件 import `@heroui/react`）。

## 四、功能移植分档

- **照搬**：键盘快捷键、字体/排版设置、亮暗各选多主题、卡片缩略图列表、底部胶囊筛选、快捷键帮助弹窗。
- **改造**：图片画廊手势（复用 Gist Lightbox）、卡片图片尺寸切换（复用 `hasThumbnail`）。
- **放弃**：保存到第三方服务（Miniflux 集成专属）、HeroUI 手搓替代（已决定直接引入）。

## 五、风险

- **布局级改动**：中栏 930px → ~500px 会连带影响正文宽度与移动端断点，不是纯换皮。
- **移动端逻辑脆弱**：Gist 移动端滚动/顶栏方案在 2026-08 仍在修（见上游近三次提交），改布局要重点回归。
- **HeroUI v3 与 Radix 并存**：两套交互原语会造成体积与风格割裂，迁移需按组件分批，避免「半 HeroUI 半 Radix」的中间态长期存在。
