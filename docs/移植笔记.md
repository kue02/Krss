## 一、调色板迁移：Gist 的 shadcn 变量 → HeroUI v3 token

**冲突的本质**：Gist 用 shadcn 约定，变量是 **HSL 三元组**（`--background: 0 0% 100%`，用时 `hsl(var(--background))`）；HeroUI v3 的同名变量是**完整颜色**（`--background: oklch(...)`）。同名不同义，直接共存会互相覆盖 → `hsl(rgb(...))` 非法，声明被丢弃。

**解法**（`src/index.css`）：

1. 删掉 Gist 自己那套调色板定义（`:root` 与 `.dark` 里的 HSL 三元组），只保留布局/动效变量。
2. `@theme` 里的 `--color-*` 全部改成指向 HeroUI token：

   | Gist 语义 | 映射到的 HeroUI token |
   |---|---|
   | background | `--background` |
   | foreground | `--foreground` |
   | card / card-foreground | `--surface` / `--surface-foreground` |
   | popover / -foreground | `--overlay` / `--overlay-foreground` |
   | primary / -foreground | `--accent` / `--accent-foreground` |
   | secondary / muted / accent | `--surface-secondary` |
   | muted-foreground | `--muted` |
   | destructive | `--danger` |
   | border / input | `--border` |
   | ring | `--focus` |

   这样所有既有组件（用的都是 `bg-background`、`text-muted-foreground` 这类 Tailwind 类）**零改动**就换上了 Nextflux 的配色。
3. 全文 `hsl(var(--X))` → `var(--映射后的token)`；带透明度的 `hsl(var(--X) / 0.5)` → `color-mix(in srgb, <token> 50%, transparent)`。

## 二、主题切换：`data-theme` 驱动五套配色

- HeroUI 只认 `.light/.dark/[data-theme=light|dark]`；自定义主题（stone/leaf/nord-dark）由 `src/styles/nextflux-theme.css` 用 `[data-theme=…]` 覆写同一批 token。
- 应用方式（`src/hooks/useTheme.ts`，对齐 Nextflux 的 themeStore）：`class` 承载 light/dark 语义，`data-theme` 承载具体配色 —— `<html class="light" data-theme="stone">`。
- 首屏防闪：`index.html` 里的内联脚本同步读取 `gist-theme` / `gist-light-theme` / `gist-dark-theme`。
- css 层叠依据：HeroUI 的 token 在 `@layer theme`，我们的覆写在 `@layer base`（HeroUI 自己声明的层序 `theme, base, components, utilities` → base 优先级更高），所以能盖住。
- 柔影 token 用 `@utility` 接到 Tailwind：`shadow-nf` / `shadow-nf-md` / `shadow-nf-inner` / `shadow-nf-btn`。

## 三、踩过的坑（会反复遇到）

1. **未分层的全局规则会压过所有 utility**：Gist 原先写了未分层的 `* { border-color: … }`，导致卡片上的 `border-transparent` 完全失效（边框永远显形）；同一类坑还有未分层的 `.safe-area-*`（`padding-top: env(...)`）压掉了布局容器的 `sm:pt-[17px]`，浮层面板上边距死活不生效。**凡是自定义 CSS 类/全局覆盖，一律放进 `@layer base` 或 `@layer components`。** 排查手法：`getComputedStyle(el)` 读实际生效值，再看该规则是否带 layer。
2. **`@import` 必须在文件顶部**：把 `./styles/nextflux-theme.css` 插在 `@plugin` 之后会报错；顺序还决定层叠优先级，要放在 `@import "@heroui/styles"` 之后。
3. **HeroUI v3 装完要补 peer 依赖**：`react-aria`、`react-aria-components`、`@react-aria/ssr`、`@react-aria/i18n`、`@react-aria/utils`（不然运行时报缺依赖）。
4. 项目规定用 bun；本机原先没有 bun，已用 `npm i -g bun` 装上（1.4.2）。
