# Krss 移动端 v2 设计规范 —— 纸页 · Paper Rail

> 2026-11-21 / mobile-redesign-v2
> 上一版（2026-10）把移动端做成了「缩小的桌面三栏」；主树这一个月新增了插件视图、设置改版、
> 翻译与 AI 摘要。本版重新按**手机原生阅读器**来做：先解决可达性，再统一纸面视觉。

## 1. 方向

**纸页 · Paper Rail。**

- 纸面是底色，内容直接落在纸上：列表不再是一张张浮起的卡片，而是整宽、细线分隔的目录。
- 顶栏是一条安静的「报头」：左侧菜单，中间标题与未读数，右侧只有搜索与更多。
- 底栏是四条「内容轨」：文章 / 社交 / 图片 / 通知。列表页常驻；进入详情全屏阅读时让位给正文，返回即恢复。所有一级切换都在拇指区完成。
- 强调色只做三件事：未读、当前选中的轨、阅读进度。其余一律用墨色与灰阶。

明确不做的事：不做玻璃拟态堆叠、不做彩色渐变、不把桌面三栏压进手机、不用 hover 才能触发的交互。

## 2. 尺寸与栅格

| 项目 | 值 |
| --- | --- |
| 设计基准 | 390 × 844（iPhone 14 / 15 逻辑像素） |
| 顶栏内容高 | 44px，另加 `env(safe-area-inset-top)` |
| 底部导航内容高 | 56px，另加 `env(safe-area-inset-bottom)` |
| 页面左右留白 | 16px（列表行内边距）；文字栏最大 65ch |
| 最小点击区 | 44 × 44px；底栏每格 ≥ 78 × 56px |
| 圆角 | 列表缩略图 8px；面板 22px；按钮全圆 |
| 分割线 | 1px，`border/45`；只在纸面列表与面板标题下出现 |

所有固定栏必须同时处理安全区：`padding-top: env(safe-area-inset-top)` /
`padding-bottom: env(safe-area-inset-bottom)`；列表底部额外留
`calc(56px + env(safe-area-inset-bottom) + 16px)`，保证最后一条不被底栏压住。
`index.html` 必须是 `viewport-fit=cover`，否则 `env()` 恒为 0。

## 3. 颜色与字

全部取主树的 theme token，不新增主题：

| 语义 | token |
| --- | --- |
| 纸面 | `--background`（stone 下 `#E3E0DB`） |
| 面板 / 浮层 | `--overlay`、`--surface` |
| 主墨 | `--foreground` |
| 次墨 | `--muted-foreground` |
| 细线 | `--border` |
| 强调 | `--accent`（stone 下 `#D85E4B`） |

字体沿用系统 UI 字体（中文优先系统黑体），不引入网络字体：

| 层级 | 字号 / 行高 / 字重 |
| --- | --- |
| 顶栏标题 | 15 / 20 / 700 |
| 列表标题 | 16 / 23 / 600 |
| 列表摘要 | 13.5 / 20 / 400 |
| 来源与时间 | 11.5 / 16 / 500–600 |
| 底栏标签 | 10 / 12 / 600 |
| 正文标题 | 26 / 34 / 700 |
| 正文 | 17 / 30 / 400 |

## 4. 组件

### 4.1 列表顶栏（`EntryListHeader` mobile）

- 44px 单行：`菜单 44 | 标题 + 未读徽标（弹性） | 刷新 44 | 未读切换 44 | 全部已读 44 | 更多 44`。
- 标题单行截断；未读数做成 10px 的小胶囊，不再单独占第二行。
- 搜索不再单独放图标，收进「更多」底部操作面板第一项；「更多」还收纳：刷新、强制拉取、
  只看未读、星标当前视图、列表 / 悬停正文切换、全部标为已读。所有行 52px 高。

### 4.2 底部内容轨（`MobileTabBar`）

- 四等分：文章、社交、图片、通知（跟随侧栏的 `CONTENT_TYPE_ORDER`，只显示已启用的类型）。
- 图标 21px，选中时图标底出现 `accent/12` 的胶囊，文字变强调色；未读角标在图标右上角。
- 56px + 安全区；顶边 1px 细线 + `background/75` 半透明 + 背景模糊。
- 切类型是一次路由导航；插件视图下切类型先退出 `?view=`。

### 4.3 详情顶栏（`EntryContentHeader` mobile）

- 44px：`返回 44 | 标题（弹性） | 星标 44 | 已读/未读 44 | 更多 44`。
- 标题在页面顶部时隐藏（正文已有大标题），向下滚动后淡入；点击标题回到顶部。
- 更多用底部操作面板：标为已读/未读、AI 摘要、翻译、原站/阅读模式、阅读设置、在浏览器打开；
  插件工具栏项放在面板底部。
- 阅读进度条改成 2–3px，紧贴顶栏下沿，避让安全区。

### 4.4 文章行（`EntryListItem` mobile）

- 整宽 `px-4 py-3.5`，行间 1px `border/45`，无卡片阴影。
- 来源行：20px favicon + 源名 + 右侧相对时间。
- 标题 16/23 两行；摘要 13.5/20，可配置 0–2 行；右侧 76px 方形缩略图。
- 未读用来源图标角标与标题墨色表达；已读标题降为次墨，不切换字重（避免换行高度跳动）。

### 4.5 下拉刷新

- 只在列表滚动到顶部时接管；阻尼拉动，超过 64px 松手触发。
- 指示器是 32px 圆片 + 旋转刷新图标，落在顶栏下沿，不遮挡内容。

### 4.6 搜索（`SearchModal` mobile）

- 全屏 `100dvh`，顶部搜索框 + 取消，底部「文章 / 订阅」两档。
- 不再显示键盘快捷键提示（手机没有键盘）；结果列表行高 ≥ 44px。

### 4.7 插件视图

- 插件视图也必须有应用级顶栏（菜单 + 「插件视图」+ 搜索）和底部内容轨；
  否则进入插件后无法打开侧栏或切换内容类型。

### 4.8 从 V1 吸收的阅读能力

- **目录**：详情右缘 44×44 热区，点开全高右侧抽屉；抽屉列出 h1–h4，当前节高亮，点条目平滑滚动并关闭；桌面仍保留 hover 面板。
- **阅读设置**：底部面板，字体四档、字号 15/16/17/19/21、行高 1.6/1.8/2.0、主题跟随系统/浅色/深色，底部给一行正文预览；所有档位 ≥44px。
- **上一条 / 下一条**：详情底部浮动胶囊，显示 `当前位置 / 总数`；只在存在当前条目所属列表时出现，按钮 40px，避开底部安全区。
- **条目长按**：列表行 520ms 长按打开操作面板；移动超过 10px 取消，触发后吞掉 click。动作分两组：这条（标已读/未读、星标、标记上方已读、豁免、按此条新建规则）与所属订阅（刷新、编辑、移动文件夹、改类型、复制 Feed/主站地址、打开主站、新建规则、删除）。
- **长按面板位置**：外观 → 移动端样式可切「底部面板」（默认）或「长按位置浮层」；浮层宽 280、贴触点弹出，靠近屏幕下缘自动翻到上方；面板用纵向 flex，标题固定、内容区独立滚动，长菜单底部动作不会被裁掉。
- **下拉刷新进度**：刷新中显示「正在刷新 · completed / total」胶囊，完成即收起。
- **byline 头像**：详情作者行 24px 圆形源头像，无图标时回退作者首字母圆块。

### 4.9 移动端样式设置

- 外观 → 「移动端样式」：
  - **侧栏显示视图切换**：默认关。关闭后移动侧栏不再重复显示内置/插件视图，底栏入口不变。
  - **长按条目的菜单位置**：底部面板（默认）/ 长按位置浮层。
- 两项都存 `useUISettings`，桌面端不受影响。

## 5. 验收

- 390 × 844 下逐屏截图：列表、详情、图片、通知、社交、侧栏、搜索、更多面板、插件视图。
- 所有可点元素实测 ≥ 44 × 44；标题不被按钮挤压（详情标题宽度 ≥ 150px）。
- `bun run test` 退出码 0；`bunx tsc -b` 通过。
