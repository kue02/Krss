## 二、踩到的坑（都已在代码里修掉并留了回归测试）

1. **「添加订阅」是第二条入库路径**：规则引擎最初只挂在 `refresh_service.saveEntries`（刷新路径）上，
   而 `feed_service.Add`（新订阅首次抓取）自己写库 —— 实测发现新订阅的第一批条目**整体绕过规则**。
   修法：`Add` 入库后同样调 `ApplyToEntries`，`FilterService` 由构造函数注入（`fix(filter)` commit）。
   教训：本项目任何「入库后要做事」的功能，都要检查这两条路径。
2. **mock 没重生成会静默挂测试**：接口加方法后必须 `PATH="$HOME/go/bin:$PATH" make gen`
   （本机原先没有 mockgen / swag / golangci-lint，已装到 `~/go/bin`）。
3. **前端 `bun run test` 长期「全绿但退出码 1」**：jsdom 缺 Web Animations API，涟漪点击抛 unhandled error（主树同样如此）。
   已补 `src/test/setup-dom.ts` + `setupFiles`，现在退出码 0（否则质量门形同虚设）。
